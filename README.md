# Zero-Trust Access Control Platform (ZTACP)

Contextual Zero-Trust Access Control Platform based on NIST SP 800-207.

## Key Capabilities
- Policy Decision Point (PDP) and Policy Enforcement Point (PEP)
- Continuous Contextual Authentication & Authorization
- Dynamic Trust Engine computing real-time Trust Scores (0.0 - 100.0)
- Granular Policy Engine supporting ABAC + RBAC rules
- Dynamic Session Management with cryptographic token binding
- SQLite WAL Persistence, FastAPI REST API, and Typer CLI
